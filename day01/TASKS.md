git status
查看当前项目状态：哪些文件新增了、修改了、删除了，哪些文件还没提交。

git add .
把当前目录的改动加入暂存区，表示这些改动准备进入下一次提交。

git commit -m "说明"
把暂存区的内容保存到本地 Git 仓库，也就是生成一个本地版本记录。

git remote add origin 仓库地址
把本地仓库和 GitHub/Gitee 上的远程仓库关联起来。
注意：这一步不是上传，只是绑定地址。

git branch -M main
把当前分支改名为 main。现在 GitHub 默认主分支一般叫 main。

git push
把本地 commit 上传到 GitHub/Gitee 远程仓库。

Git 是版本管理工具。它可以在本地记录项目每一次重要修改；配合 GitHub/Gitee，可以把这些版本同步到线上，让别人看到，也方便团队协作。如果新版本写坏了，可以查看旧版本，必要时回退。

工作区：你正在编辑的文件
暂存区：准备提交的改动
本地仓库：你电脑里的版本记录，也就是 .git 文件夹
远程仓库：GitHub/Gitee 上的线上版本
