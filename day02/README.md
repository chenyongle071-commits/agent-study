## 1. Python 虚拟环境

虚拟环境用于给当前项目创建独立的 Python 运行环境。

这样每个项目可以有自己的依赖，不会互相影响。

常用命令：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

## 我的理解

类型标注用于说明函数参数和返回值应该是什么类型。
比如用户发来一个数字，可以标注为 `int` 或 `float`；用户发来一段文本，可以标注为 `str`。类型标注本身不会自动校验用户输入，但它能让代码更清晰，也方便后续结合 FastAPI 和 Pydantic 做参数校验。

异常处理是在程序遇到不符合预期的情况时，让程序可控地失败，而不是直接崩溃。比如用户输入了不能转换成数字的内容，程序可以提示“指标值必须是数字”。

装饰器是在不修改原函数核心逻辑的情况下，给函数增加通用能力。比如多个 Agent 工具都需要记录耗时，就可以把记录耗时的逻辑写成装饰器，然后复用到多个函数上。
